# Contributing

These skills are **generated** — every file in this repo is build output, so editing it directly will be overwritten by the next release. Contributions flow through the upstream source, not this tree.

To propose a change:

1. Open an issue or PR here describing the skill change.
2. Maintainers apply it upstream; this repo regenerates on the next release.

Skills adapted from other open-source projects (e.g. `coreyhaines31/marketingskills`, MIT) keep machine-readable attribution in their `SKILL.md` frontmatter and a human-readable credit in the skill's `README.md`. Thank the original project; don't strip credit.
